# Regression Models and Gradient Descent

## Aim
To develop regression models for house price prediction and implement Gradient Descent optimization for Linear Regression.

## Technologies Used
- Python
- NumPy
- Scikit-learn
- Matplotlib

## Practical 1: Regression Models
Linear Regression and Decision Tree Regression are used to predict house prices based on house area. Their performance is evaluated using MAE, MSE, RMSE, and R² score.

## Practical 2: Gradient Descent
Gradient Descent is implemented to optimize the slope and intercept of Linear Regression by minimizing Mean Squared Error. A graph is plotted to analyze model convergence.

pip install numpy scikit-learn matplotlib



## Result
Both practicals were implemented successfully. Regression models were evaluated using performance metrics, and Gradient Descent was analyzed using the loss graph.
